# 📁 React (Vite) Folder Structure — Easy Guide

Ye README batata hai ki ek fresh **React + Vite** project mein kaunsi file/folder kya kaam karta hai. Ek baar padh lo, structure clear ho jayega.

---

## 🗂️ Complete Structure

```
app/
├── node_modules/
├── public/
│   └── vite.svg
├── src/
│   ├── assets/
│   │   └── react.svg
│   ├── App.css
│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
├── .gitignore
├── eslint.config.js
├── index.html
├── package-lock.json
├── package.json
├── README.md
└── vite.config.js
```

---

## ⚡ Quick Cheat Sheet

| # | File / Folder | Ek line mein kaam |
|---|---------------|-------------------|
| 1 | `node_modules/` | Saari installed dependencies yahan hoti hain |
| 2 | `public/` | Static files (logo, favicon) jo build process se nahi guzarti |
| 3 | `src/` | Aapka poora React code yahin likhte hain |
| 4 | `.gitignore` | Git ko batata hai kya ignore karna hai |
| 5 | `eslint.config.js` | Code ke errors aur style check karta hai |
| 6 | `index.html` | Main HTML template, yahin React mount hota hai |
| 7 | `package.json` | Project ka ID card (name, scripts, dependencies) |
| 8 | `package-lock.json` | Dependencies ke exact versions lock karta hai |
| 9 | `README.md` | Project ki description / documentation |
| 10 | `vite.config.js` | Vite ki configuration |

---

## 1. 📦 `node_modules/`

- **Purpose:** Project ko jitne bhi packages/dependencies chahiye, sab isi folder mein hote hain.
- **Generated by:** `npm install`
- **Tip:** Isko manually mat chhedo, ye auto-managed hai. `.gitignore` se Git mein exclude hota hai.

> 💡 **Simple samjho:** Jaise ghar ke saaman ka godown hota hai, waise ye dependencies ka godown hai. Delete bhi kar do toh `npm install` se wapas aa jayega.

---

## 2. 🌐 `public/`

- **Purpose:** Static files rakhne ke liye jo **Vite build process se nahi guzarti**.
- **Example:** `vite.svg` — Vite ka default logo.
- **Use case:** Logos, favicon jaisi public assets yahan rakho.
- **Access:** Code mein seedha `/vite.svg` likhkar use karo.

```jsx
<img src="/vite.svg" alt="Vite logo" />
```

> 💡 **Note:** `public/` ki files ko import nahi karna padta, bas `/` se path de do (`public` likhne ki zaroorat nahi).

---

## 3. 🧠 `src/` (Source)

Ye **main folder** hai jahan aapki React application rehti hai. Aap 90% kaam yahin karoge.

| File / Folder | Kaam |
|---------------|------|
| `assets/` | Images, logos, icons store karne ke liye |
| `App.jsx` | App ka **dil** ❤️ — main component. UI logic yahan likhte hain. `main.jsx` ke andar use hota hai |
| `App.css` | `App.jsx` ki styling. Logic aur design ko alag rakhne mein help karta hai |
| `index.css` | **Global styles** — poori application par apply hoti hain |
| `main.jsx` | **Entry point.** `App.jsx` ko DOM mein render karta hai |

> 💡 **`assets/` vs `public/` — fark kya hai?**
> `src/assets/` ki files ko **import** karke use karte hain (Vite inhe process/optimize karta hai).
> `public/` ki files ko seedha `/filename` se access karte hain (koi processing nahi).

```jsx
// src/assets se image use karna
import reactLogo from './assets/react.svg'

<img src={reactLogo} alt="React logo" />
```

---

## 4. 🙈 `.gitignore`

- **Purpose:** Git ko batata hai ki kaunsi files/folders ignore karni hain (jaise `node_modules`, `.env` etc.).

> 💡 **Kyun zaroori hai?** `node_modules` bahut heavy hota hai, aur `.env` mein secrets (API keys) hote hain. Inhe GitHub par push nahi karna chahiye.

---

## 5. 🧹 `eslint.config.js`

- ESLint **errors catch karta hai** aur **code style enforce** karta hai.
- Ye config file **rules aur plugins** define karti hai.

---

## 6. 📄 `index.html`

- Main HTML file jo Vite **template** ki tarah use karta hai.
- Isme ye line hoti hai jahan React mount hota hai:

```html
<div id="root"></div>
```

---

## 7. 📋 `package.json`

**Bahut important file hai** — ye aapke project ko describe karti hai.

Isme hota hai:
- Project ka **name, version**
- **Scripts** (`dev`, `build`, etc.)
- **Dependencies**

---

## 8. 🔒 `package-lock.json`

- `npm` isko **auto-generate** karta hai.
- Dependencies ke **exact versions lock** karta hai, taaki sabke system par same versions chalein (consistency).

> 💡 Isko manually edit mat karo.

---

## 9. 📝 `README.md`

- Project description ke liye **Markdown file**.
- Isme instructions, use ki gayi tech, aur project run karne ka tarika likh sakte ho.

---

## 10. ⚙️ `vite.config.js`

- **Vite ki configuration file.**
- Isme plugins add karte hain, aur default settings change karte hain jaise **aliases, server port** etc.

```js
// Example: port change karna
export default defineConfig({
  plugins: [react()],
  server: { port: 3000 },
})
```

---

## 🔄 Poora Flow — Sab Kaise Connect Hota Hai?

```
index.html  ──►  main.jsx  ──►  App.jsx  ──►  Aapka UI
 (<div id="root">)   (React ko mount karta hai)   (Main component)
```

1. Browser `index.html` load karta hai.
2. `index.html` mein `main.jsx` script attach hoti hai.
3. `main.jsx`, `App.jsx` ko `#root` div mein render karta hai.
4. `App.jsx` mein aap apne baaki components use karte ho.

---

## 🚀 Project Run Karne ke Commands

```bash
# 1. Dependencies install karo (node_modules banega)
npm install

# 2. Development server start karo
npm run dev

# 3. Production build banao
npm run build
```

---

## ✅ Yaad Rakhne Wali Baatein

- ❌ `node_modules/` aur `package-lock.json` ko manually edit mat karo.
- ✅ Code `src/` ke andar likho.
- ✅ Static files (favicon etc.) `public/` mein rakho.
- ✅ Secrets (`.env`) ko `.gitignore` mein zaroor rakho.
- ✅ Naya package chahiye? `npm install <package-name>` use karo — `package.json` khud update ho jayega.
