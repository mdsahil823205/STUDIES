## 💡 Tips

1. **Order follow karo** — Phase 1 se shuru karo, beech se nahi.
2. **Har concept ke baad chhota project banao.**
3. **Docs padhne ki aadat daalo** — [react.dev](https://react.dev) best resource hai.
4. **Ek tool ek time par** — Redux, Zustand, Context sab ek saath mat seekho.
5. **Roz thoda code likho** — consistency sabse important hai.
